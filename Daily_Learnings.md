# Daily Learnings 

## 15-Sep-2026

- Sign up for GitHub Copilot: Free Tier, Limited Tokens.
- Configure GitHub Copilot in VS Code
  - Add the VS Code extension for GitHub Copilot: `Ctrl+Shift+X`
  - Enable or disable GitHub Copilot in VS Code: Press the copilot icon
- Enable or disable inline suggestions in VS Code: `Ctrl+Shift+P`
- Troubleshoot GitHub Copilot in VS Code: `Ctrl+Shift+P` then ``Developer: Open Log File`` or ``Developer: Open Extensions Logs Folder.``
